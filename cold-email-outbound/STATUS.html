Before the first real send

🚦 Go-live gate — all true before we flip CEO_DRY_RUN=false

  • The segment ran through the qualification layer — correct brand, current owner, fits the caps
  • Compliance: every email carries a physical address + a working opt-out line (CAN-SPAM)
  • Copy approved by Malcolm — email 1 doesn't sell, anti-AI-tell pass done
  • Mailboxes warmed (score ≥ 95), 3 dead boxes reconnected; SPF/DKIM/DMARC pass; tracking OFF + plain-text
  • That exact segment re-verified fresh, bounce rate < 3% (hard stop)
  • Field + fallback test-add passed (no broken variables)
  • Reply webhook live so responses route to the CRM, not a black hole
  • Suppression confirmed against current GHL (no one already in a conversation)
  • Start small — one segment, one brand, watch it land before scaling
